# TaskFlow – Smart Task Manager

TaskFlow is a web-based task management application developed using Python Flask and SQLite. It helps users organize daily tasks, track deadlines, monitor productivity, and manage their work efficiently.

## Features

- User Registration and Login
- Email OTP Verification
- Secure Password Hashing
- Add, Edit and Delete Tasks
- Mark Tasks as Completed
- Task Search and Filters
- Priority Management
- Due Date Tracking
- Calendar View
- Productivity Analytics
- Email Deadline Reminders
- In-App Notifications
- User Profile and Photo Upload
- Responsive Dashboard

## Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
- SMTP Email Service
- APScheduler

## Installation and Setup

1. Clone the repository.
2. Navigate to the project folder.
3. Create a virtual environment.
4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Configure your `.env` file with the required environment variables.
6. Run the application:

```bash
python app.py
```

7. Open your browser and visit:

```text
http://127.0.0.1:5000
```
